# Licensing

This project changed licence partway through its history. Both licences remain
in force — which one applies depends on which version you took the code from.

| Versions | Licence | File |
|---|---|---|
| Up to and including `v0.0.12` (commit `aec1e4c`, tagged `v0.0.12-mit`) | MIT | [`LICENSE-MIT`](LICENSE-MIT) |
| `v0.1.0` and later | GNU GPL v3.0 or later | [`LICENSE`](LICENSE) |

## Why both

An MIT grant cannot be withdrawn. Everything published under it stays available
under MIT for good, and the tag `v0.0.12-mit` marks that boundary so anyone can
find it. The change applies only to work released afterwards.

## What this means for you

- **Using the site.** Nothing to do. Open it and generate art.
- **Copying code from `v0.1.0` or later.** Your project must also be GPL-3.0
  compatible, and you must make your source available.
- **Copying code from `v0.0.12` or earlier.** MIT terms apply — keep the
  copyright notice and you are done.
- **Contributing.** Contributions are accepted under GPL-3.0-or-later, the same
  licence the project ships under.
